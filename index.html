Simple YAML, powerful results

workflow.yaml 
# Code review workflow
name: code-review
version: "1.0.0"

inputs:
  - name: file
    type: string
    required: true

states:
  initial: read

  read:
    type: step
    command: cat "{{.inputs.file}}"
    on_success: analyze

  analyze:
    type: agent
    provider: claude
    prompt: |
      Review this code for bugs and security issues:
      {{.states.read.Output}}
    on_success: report

  report:
    type: step
    command: echo "Analysis complete"
    on_success: done

  done:
    type: terminal
    status: success

Define your entire workflow in a single YAML file. Human-readable, version-controllable, and production-ready.
